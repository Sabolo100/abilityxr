Privacy Policy

Last updated: September 2026

OpenClaw Eszter is a private automation assistant available only to authorized users.

Information accessed

When a user explicitly authorizes Google access, OpenClaw Eszter may access information from the Google services for which permission has been granted, including:

  • Gmail messages, message content and message metadata
  • Google Drive files, folders and file metadata
  • Google Docs content
  • Google Sheets content

OpenClaw Eszter only accesses data necessary to perform tasks requested by the authorized user.

How information is used

Google user data is used only to provide the functionality requested by the user. This may include reading an incoming instruction, retrieving or processing documents, generating a response, or sending an email reply when explicitly requested or configured.

Google user data is not used for advertising, profiling or marketing purposes.

Google user data is not sold.

AI processing

To complete requested tasks, relevant content may be processed by AI model providers or technical infrastructure providers configured for the assistant.

Only information required to perform the requested task is intended to be sent for such processing.

Data sharing

User data is not shared with unrelated third parties.

Data may be transmitted to service providers that are technically necessary to operate the assistant, such as cloud infrastructure, API providers or AI processing services.

Data storage

The assistant may temporarily store information required for task execution, configuration, authentication or operational continuity.

OAuth credentials and access tokens are stored using protected credential storage where available.

The service does not intentionally create a permanent independent archive of a user's Google account data beyond what is required for operation or explicitly requested by the user.

User control

Users may revoke Google access at any time through their Google Account security and permissions settings.

An authorized user may also request that access to their Google services be discontinued.

Google API Services

OpenClaw Eszter's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Security

Reasonable technical measures are used to restrict access to authorized users and protect authentication credentials and connected services.
